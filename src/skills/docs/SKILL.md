# Docs

Write clear, concise technical documentation. Not verbose. Relaxed and friendly tone.

## Style Rules

- The page title should be a word or a 2-3 word phrase
- The description should be one short line, not starting with "The", not repeating the title, 5-10 words long
- Chunks of text should not be more than 2 sentences long
- Each section is separated by a divider of 3 dashes
- Section titles are short with only the first letter capitalized
- Section titles are in the imperative mood
- Section titles should not repeat the term used in the page title
- For JS or TS code snippets, remove trailing semicolons and unnecessary trailing commas
- Commit messages for documentation changes are prefixed with `docs:`
